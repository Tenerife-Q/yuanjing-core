**对于区块链部分：**

针对社交媒体环境下图像易被压缩裁剪导致传统校验哈希失效、以及多模态检测结果缺乏不可篡改存证的问题，我们完成了区块链存证后端与 Python SDK 的开发：

1. **图像感知指纹与抗压缩处理**：引入 pHash 感知哈希算法与 SHA-256 密码学哈希结合的双重指纹机制。在保留像素级防调包校验的同时，使系统能够容忍社交媒体传输中的良性压缩与分辨率调整，解决传统校验方法鲁棒性不足的问题。
2. **存证数据结构与防篡改签名**：采用 Merkle Mountain Range (MMR) 增量树结构存储判定证据包，保证分析记录的时间顺序与不可篡改性。同时结合 Ed25519 数字签名算法对模型判决结论与置信度进行私钥签名，提供具备可追溯性的零信任审计证明。
3. **多模态模型与链端轻量化接口**：设计并实现了标准 Python 桥接模块（SDK），将模型的输出预测（标签与置信度）自动转换为链上存证 Payload，实现了“多模态模型推理 — 接口转换 — 链上存证”的闭环联调，保证了前端与区块链后端的高效衔接。
